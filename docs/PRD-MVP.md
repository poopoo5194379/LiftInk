# LiftInk MVP 功能清单与 PRD

版本：草案 0.1，2026-11-03。事实状态：`已接入`、`部分`、`未做`；优先级表示**进入首个可发布 MVP 的必要性**，不是代码完成度。前置判断见[产品基线](PRODUCT-BASELINE.md)。

## 功能清单

| 模块 | 功能 | 优先级 | 现状 | MVP 验收结果 |
| --- | --- | --- | --- | --- |
| 本地数据 | 索引和文档可靠提交、恢复、保存失败提示、图片引用安全 | P0 | 部分 | 已确认保存的笔记可重开；故障时不静默覆盖或丢图 |
| 输入与画布 | 数位板实测、坐标/缩放统一、大笔迹性能 | P0 | 部分 | 25%/100%/400% 对齐；目标设备无悬挂笔迹；性能达实测阈值 |
| 日常编辑 | 钢笔/荧光笔/橡皮、撤销/重做、套索移动/缩放/复制 | P0 | 部分 | 每个动作一步撤销；重开后内容一致 |
| 页面 | 新建、切换、删除、重排、纸张类型 | P0 | 部分 | 多页顺序和内容重开不变；删除可撤销 |
| 输出 | 原生可移植备份、单页/整篇 PDF 与 PNG 导出 | P0 | 未做 | 另一台机器可恢复原生笔记；导出与预览一致 |
| 基础组织 | 标题、文件夹、最近笔记、搜索元数据 | P0 | 部分 | 不靠演示数据完成新建、定位、重开 |
| 资料批注 | PDF 只读底图、来源复制、批注和导出 | P1 | 未做 | 外部原件移动后笔记仍完整 |
| 高级编辑 | 局部擦除、文本/形状、连续翻页、书签 | P1 | 未做 | 按独立需求验收 |
| 学习工作流 | 双开、摘录回链、遮挡复习 | P2 | 未做 | 先验证实际任务再排期 |
| 增强功能 | 录音、OCR、AI、同步、协作 | P2 | 演示或未做 | 单独立项与隐私评估 |

**最小 P0 集合**：本地数据 + 输入与画布 + 日常编辑 + 页面 + 输出 + 基础组织。六项同时通过验收，才称为 MVP；当前版本没有达到。图片/截图已有初版，可保留，但不用于掩盖以上缺口。

## 核心用户路径

1. 启动 → 首页/最近笔记 → `新建笔记` 或 Ctrl/Cmd+N → 新文档。目录尚未读完时禁用新建并提示。
2. 选纸张、落笔、擦除或套索修改 → UI 显示“保存中/已保存/保存失败”。每个提交的编辑动作进入本次打开期间的撤销历史；切换笔记后不承诺保留撤销栈。
3. 展开页面栏 → 新增、切换、删除或重排。操作作用于当前笔记；删除最后一页应被阻止；页面变化和笔迹一起保存。
4. 返回首页或关闭窗口 → 等待待提交写入。写入失败须给“继续编辑/仍要退出”，默认继续编辑。
5. 重开 → 从最近笔记或搜索进入同一文档。损坏主文件可从有效备份恢复时提示核对；无有效备份时保持原文件并阻止覆盖。
6. 导出/备份 → 选择范围与目标路径 → 完成后显示路径；失败保留原文档。导出文件不承诺可继续编辑，原生备份可以恢复编辑。

## 字段与规则

| 对象 | 关键字段与规则 |
| --- | --- |
| 笔记索引 `NoteRecord` | `id` 稳定且唯一；`title` 去首尾空格，空值显示“未命名笔记”；`folder` 是现有固定目录路径；`tags` 为字符串数组；`trashed` 是软删除标志。当前代码的标题、目录保存由索引异步写入，跨文件事务尚缺。 |
| 文档 `NoteDocument` | `version=1`、`noteId` 与索引一致、至少 1 页；页面有稳定 ID 与 `lines/grid/blank` 纸张。当前存储校验最多 200 页、每页最多 100000 元素，序列化文档上限约 4000 万字符。 |
| 笔迹 | ID、颜色、宽度、坐标点及压力；完整一次落笔在 `pointerup` 提交；取消输入不得留下半笔。 |
| 图片 | 文档只存资源 ID 与位置/尺寸；资源 ID 是 SHA-256 加扩展名。当前允许 PNG/JPEG/WebP，解码后每边不超过 12000 像素、文件不超过 20 MB。 |
| 搜索 | 当前只匹配标题、标签、目录、摘要及演示 PDF 文件名；**不搜索笔迹或 PDF 正文**。MVP 应排除演示 PDF 与虚构摘要的误导。 |

## 异常与边界

| 场景 | 预期行为 | 当前差距 |
| --- | --- | --- |
| 写入失败/磁盘不可用 | 保留未保存提示和重试入口；关闭默认继续编辑 | 首轮已做，关窗故障流程未自动化验收 |
| 索引或文档损坏 | 有效备份恢复并提示；无备份拒绝覆盖 | 单文件已做；索引与文档仍非事务 |
| 图片文件缺失 | 占位框与提示，其余内容可打开 | 已做；资源清理规则未定 |
| 连续编辑与关闭竞态 | 已确认保存的最新提交可恢复 | 意外进程退出、断电尚未验收 |
| 同一笔记双窗口并发 | 在实现双开前禁止同文档多写；后续需修订冲突策略 | 当前主窗口单实例编辑路径，未做冲突协议 |
| 不支持的图片/超限 | 拒绝导入并给可理解的错误，不修改文档 | 代码有校验，文案需完善 |
| 截图取消/权限拒绝 | 取消无资源和历史；拒绝有明确提示 | 多屏及 macOS 权限实测未完成 |

以上是开发目标；现有行为的细节见[编辑器报告](LIVE-EDITOR-V01-REPORT.md)及[存储施工结果](DEVELOPMENT-PRIORITIES-2026-11-03.md)。变更需求时先改本文件的行为与验收，再改实现。
