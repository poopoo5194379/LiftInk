# 竞品对照表

更新：2026-11-03。只比较与 LiftInk 首轮任务有关的 3 个产品。功能和定价会变，发布决策前重新打开链接核对。用户评价是平台样本，不能推断 Windows 数位板用户的总体偏好。更完整的一手资料见[竞品研究](COMPETITOR-RESEARCH-2026.md)。

| 统一维度 | Xournal++ | Goodnotes | Notability | 对 LiftInk 的决定 |
| --- | --- | --- | --- | --- |
| 主要使用情境 | 桌面手写、PDF 批注；支持 Windows/macOS/Linux 与数位板 | 多平台笔记、PDF、整理与同步；功能因平台和方案而异 | 笔记、文档批注、录音与复习；以 Apple 端体验见长 | 首轮只承诺桌面数位板写、改、存、导出 |
| 核心功能 | 笔、橡皮、图层、页面、PDF、设备输入配置 | 套索、模板、目录/书签、搜索、PDF、录音等 | 可定制工具箱、页面管理、录音回放、双笔记等 | P0 补可靠性、缩放、选择与多页；P1 再做 PDF 底图 |
| 体验观察 | 设备映射与工具选项丰富；不同驱动需要实测 | 书写后能整理和找回；部分工具有平台限制 | 课堂记录和回看路径完整 | 保留明确的保存状态和低切换成本；不要照搬移动端手势 |
| 定价（官方公开信息） | 开源，可免费使用 | Free 有文件数量限制；美国 Essential 标价 $11.99/年，地区和方案会变 | Starter 免费、付费分层；价格按官网当前页面 | LiftInk 尚未定价，不以旧价格作商业模型 |
| 公开用户评价证据 | GitHub issue 有 Windows 笔侧键问题报告，属于个案 | 美国 App Store 约 4.7/5、46 万余评分；评论同时有易用肯定和具体故障反馈 | 美国 App Store 约 4.8/5、45 万余评分；评论肯定课堂笔记和录音，也提出改进需求 | 评论只用于发现待测场景；用本产品访谈和测试定优先级 |

资料：[Xournal++ 官网](https://xournalpp.github.io/)与[官方仓库](https://github.com/xournalpp/xournalpp)、[笔侧键 issue](https://github.com/xournalpp/xournalpp/issues/7331)；[Goodnotes 方案](https://www.goodnotes.com/pricing)与[App Store 评价](https://apps.apple.com/us/app/goodnotes-ai-notes-docs-pdf/id1444383602?see-all=reviews)；[Notability 方案](https://support.gingerlabs.com/en-us/articles/16300172-notability-subscription-faq)与[App Store 评价](https://apps.apple.com/us/app/notability-ai-notes-planner/id360593530?see-all=reviews)。

**结论是产品假设**：三者都覆盖“写”，但 LiftInk 的第一道竞争门槛是 Windows 数位板上的稳定输入与可恢复、可导出的多页笔记。尚无证据支持“更好用”或“更便宜”的宣传语。
