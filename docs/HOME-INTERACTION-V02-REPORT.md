# LiftInk 首页交互 V0.2 对照

日期：2026-11-01，导航和笔记页入口于 2026-11-02 更新。依据用户提供的《LiftInk（仰墨）桌面端交互设计规范 V0.2》。

## 已落实的首页模拟交互

| 模块 | 当前行为 |
| --- | --- |
| 全局搜索 | Ctrl/Cmd + K 聚焦；按标题、标签、目录、模拟摘要和 PDF 文件名实时过滤；↑/↓ 选择，Enter 打开笔记页或显示 PDF 阶段提示，Esc 关闭；结果显示类型、位置和摘要。 |
| 最近笔记 | 默认四张；悬停显示操作；可收藏、重命名、移动、移入演示回收站，也可拖至左侧文件夹。常用文件按收藏状态过滤。 |
| 书写概览 | 7／30／90 天切换折线图；鼠标悬停或键盘聚焦采样点显示日期和书写页数。指标仍为视觉样例值。 |
| 思绪拾光 | 7／30／90 天切换；悬停显示模拟词频和关联数量；点击进入关联笔记列表。 |
| 日历与日程 | 月份和日期切换；“今天”回到样例日期 2025-01-21；所选日期可新增、修改、完成和删除日程。目标勾选同步更新进度。 |
| 快捷键与入口 | Ctrl/Cmd + N 直接创建会话内空白笔记并打开笔记页；语音、导入、思维导图和白板入口自 V0.3 起进入各自工作区。具体边界见工作区报告。 |

## 与规范仍有差异

- 当前四张卡和日程是内存 Mock 数据，重新打开应用后恢复初始状态；没有本地保存、索引、OCR 或真实 PDF 预览。
- 点击笔记已打开笔记页布局，页面缩略图可按需展开，标题和位置可在当前会话中修改。笔迹、真实内容恢复与本地保存尚未接入。
- “查看全部”现进入独立的最近文件列表，包含模拟笔记与 PDF；PDF 仍仅显示阶段提示。
- 首页以 P1 视觉样例的 2025-01-21 作为演示“今天”；它不是设备当前日期。接入真实日历数据时应切换到系统日期。
- 词频、书写页数与折线图均为样例数据，尚未由笔记内容计算。
